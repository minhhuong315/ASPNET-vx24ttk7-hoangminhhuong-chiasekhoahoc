# XÂY DỰNG WEBSITE CHIA SẺ KHÓA HỌC TRỰC TUYẾN

## 2. Giới thiệu

Đề tài xây dựng website chia sẻ khóa học trực tuyến nhằm hỗ trợ người dùng
tìm kiếm, đăng ký và tham gia các khóa học trên hệ thống.

Hệ thống hướng đến ba nhóm người dùng chính:

- Học viên (Student)
- Giảng viên (Instructor)
- Quản trị viên (Administrator)

## 3. Công nghệ sử dụng

- ASP.NET Core MVC
- .NET 10
- Entity Framework Core
- ASP.NET Core Identity
- SQL Server
- HTML5, CSS3
- Bootstrap
- JavaScript / jQuery
- Git và GitHub

## 4. Các chức năng dự kiến

### Học viên
- Đăng ký, đăng nhập
- Quản lý thông tin cá nhân
- Xem và tìm kiếm khóa học
- Đăng ký khóa học
- Theo dõi tiến độ học tập
- Đánh giá khóa học
- Quản lý danh sách yêu thích

### Giảng viên
- Tạo và quản lý khóa học
- Quản lý chương học và bài học
- Theo dõi học viên tham gia khóa học

### Quản trị viên
- Quản lý người dùng
- Quản lý khóa học
- Quản lý danh mục
- Theo dõi thông tin tổng quan hệ thống
